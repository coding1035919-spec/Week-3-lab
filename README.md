# Week 3 Lab – Bivariate Analysis Part 1

## Overview

This lab explored bivariate analysis techniques for examining relationships between continuous and categorical variables using Plotly and Pandas.

---

## Tasks Completed

### Bivariate Boxplots

Created boxplots to compare age distributions across different geographical regions. Additional features such as gender colouring and faceting by credit card ownership were added to improve analysis.

### Histograms

Created histograms showing the distribution of customer age grouped by geography. Additional visualisations were generated by faceting the charts by gender and modifying the bin sizes.

### Bar Charts

Calculated average credit scores using pandas groupby functions and visualised the results using bar charts. A stacked bar chart was also created to compare average credit scores across geography and gender.

---

## Reflection

In this lab, I used several visualisation techniques to explore relationships between customer characteristics. Boxplots helped compare age distributions across different groups, while histograms provided insights into the frequency of ages within the dataset. Bar charts were useful for comparing average credit scores across categories. By extending the visualisations with additional variables such as gender and credit card ownership, I gained a better understanding of how different factors relate to one another. The lab demonstrated the value of bivariate analysis for identifying patterns and differences within data.

# Week 3 Lab – Bivariate Analysis Part 2

## Overview

This lab focused on analysing relationships between continuous variables using several visualisation techniques including scatter plots, bubble charts, correlation heatmaps and line charts.

---

## Tasks Completed

### Scatter Plot Analysis

Created scatter plots to examine the relationship between infant mortality and life expectancy across countries.

### Bubble Chart Analysis

Extended the scatter plot into a bubble chart by using GDP per capita as the bubble size, allowing three variables to be analysed simultaneously.

### Correlation Matrix and Heatmap

Generated a correlation matrix and heatmap to identify positive and negative relationships between health and development indicators.

### Line Chart Analysis

Created line charts and multi-line charts to compare trends and patterns across multiple variables and countries.

### Data Normalisation

Applied normalisation to numerical variables before plotting multiple indicators on the same chart to ensure meaningful comparisons.

---

## Reflection

This lab demonstrated how visualisations can be used to identify relationships between continuous variables. Scatter plots and bubble charts helped reveal connections between infant mortality, life expectancy and GDP per capita. The correlation heatmap provided a numerical summary of the strength and direction of relationships between variables. Through normalisation and multi-line charts, I was able to compare different development indicators across countries and better understand the association between economic development, education and health outcomes.
